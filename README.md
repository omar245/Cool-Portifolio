# Daily Flow

You are a senior front-end engineer. Build a fully functional, production-quality daily productivity web app using pure HTML, CSS, and JavaScript (no frameworks).

Requirements:

Deliver 3 separate files:

index.html

style.css

script.js

UI/UX:

Modern, clean, premium UI (inspired by glassmorphism + blur + smooth animations)

Fully responsive (mobile-first)

Smooth transitions and hover effects

Use good typography and spacing

Dark mode by default

Features:

Live Clock

Real-time updating digital clock

Daily Checklist

Tasks:

Study 2h (x3)

Programming 1h (x2)

Workout

Each task is a checkbox

Show completed vs remaining tasks

Subjects Tracker

Subjects:

Physics, Chemistry, Arabic, Math, English, History

Each subject has:

Input field to write what was completed

Progress indicator or completion status

Prayer Tracker

Fajr, Dhuhr, Asr, Maghrib, Isha

Checkbox for each prayer

Workout Tracker

Checkbox + optional notes

Daily Analysis Section

Show:

Completion percentage (based on checklist)

Visual progress bar

Summary text like: “Good job” / “Needs improvement”

Persistence

Use localStorage to:

Save all checkboxes

Save subject inputs

Restore state on reload

Reset Button

Clears all saved data

Resets UI cleanly for next day

Advanced UX:

Animate progress bar smoothly

Add subtle glow or highlight for completed tasks

Add small micro-interactions (hover, click feedback)

Prevent bugs and ensure clean state management

Code Quality:

Clean, well-structured code

No bugs

Proper naming conventions

Comments explaining key logic

Output format:

Return ONLY:

index.html (full code)

style.css (full code)

script.js (full code)

No explanations. No extra text.
